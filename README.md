# 🏦 Banking Customer Analysis

## 📌 Project Overview

Banking Customer Analysis is a data analytics project focused on understanding banking customer profiles, financial characteristics, account information, and customer behavior.

The project uses "Python for data analysis and Exploratory Data Analysis (EDA)" and "Power BI for interactive data visualization and dashboard development".

The objective is to transform banking customer data into meaningful insights by analyzing customer characteristics, financial attributes, account balances, loans, credit cards, and other banking-related information.


# 🎯 Business Problem
Banks maintain large amounts of customer data containing demographic, financial, and banking-related information.

However, raw customer data alone does not provide meaningful business insights.

This project focuses on exploring the data to answer questions such as:

* Who are the customers using banking services?
* What are the characteristics of the customers?
* How are customers distributed across different categories?
* What patterns can be observed in customer income and account balances?
* How are loans and credit cards distributed among customers?
* What relationships exist between different financial variables?
* Which customer characteristics can provide useful business insights?
* How can banking data be presented through an interactive dashboard?



# 🎯 Project Objectives
The major objectives of this project are:

1. Understand the structure and characteristics of the banking customer dataset.
2. Clean and prepare the data for analysis.
3. Perform Exploratory Data Analysis using Python.
4. Analyze customer demographic and financial information.
5. Explore account balances, income, loans, and credit card information.
6. Analyze distributions of important customer attributes.
7. Identify relationships between numerical variables using correlation analysis.
8. Create meaningful data visualizations.
9. Build an interactive Power BI dashboard.
10. Convert raw banking data into meaningful business insights.

# 🗂️ Dataset
The project uses banking customer data containing information related to customer profiles and financial characteristics.

The dataset includes attributes related to:

* Customer demographics
* Income
* Account balance
* Loans
* Credit cards
* Banking relationships
* Customer categories
* Other financial attributes

The data is explored and analyzed using Python before being presented through Power BI visualizations.
